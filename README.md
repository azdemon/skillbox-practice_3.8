# 3.8 Практическая работа
## Цель практической работы
### Закрепить навыки создания взаимодействия между Blueprints.


### Что нужно сделать
- Создайте проект ThirdPerson Template.
- Реализуйте интерфейс BPI_Switchable для реализации логики включения и выключения.
- Создайте светильник, который реализует интерфейс BPI_Switchable для включения и выключения света.
- Создайте кнопку, которая реализует интерфейс BPI_Switchable для включения и выключения всех светильников на локации.
- Реализуйте логику включения и выключения светильников при переключении кнопки за счёт диспатчера кнопки, на который должен подписываться каждый светильник.
- Сделайте так, чтобы игрок мог в определённом радиусе от кнопки включать и выключать эту кнопку, нажимая на E.
